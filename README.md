### 👨‍💻 Executive Summary

I am a software engineer focused on building **high-performance, native desktop applications** with modern design languages (**Windows 11 Fluent Design, Dark Glass, Mica Alt**) and robust backend architectures. 

My work emphasizes **responsiveness, hardware-accelerated rendering, memory efficiency, and intuitive UI/UX**. Whether architecting secure archive utilities, designing multimedia streaming engines, or hardening browser routing, I prioritize writing clean, maintainable code with zero unnecessary bloat.

### 🏗️ Engineering Principles

```
  ┌────────────────────────┐      ┌────────────────────────┐      ┌────────────────────────┐
  │   ⚡ Zero Bloat        │      │   🎨 Aesthetic Polish   │      │   🛡️ Hardened Security │
  │   Low CPU/RAM usage    │ ───► │   Windows 11 Fluent    │ ───► │   Zip-Slip protection  │
  │   Hardware accelerated │      │   Mica Alt dark theme  │      │   Encrypted vaults     │
  └────────────────────────┘      └────────────────────────┘      └────────────────────────┘
```

1. **Native Performance Over Overhead**: Prioritizing compiled binaries, hardware Direct3D pipelines, and responsive thread delegation over heavy, sluggish web wrappers.
2. **Visual Ergonomics**: Desktop software should be functional and visually stunning, integrating seamlessly with Windows 11 aesthetics.
3. **Resilience & Safe IO**: Defensive input validation, sanitization of untrusted payloads, and transactional file system modifications.
