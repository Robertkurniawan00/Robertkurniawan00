### Open Source Projects

#### [ZiPack](https://github.com/Robertkurniawan00/ZiPack)
A fast, lightweight archive manager and compression utility for Windows 10 and 11. Built with PyQt6 and integrated with native Windows Desktop Window Manager (DWM) materials and shell context menus.
* Archive creation and extraction for ZIP, 7Z, TAR, RAR, and ISO formats with multi-volume splitting.
* Integrated security checks including path traversal (Zip-Slip) protection and archive integrity verification.
* Direct in-archive search and regex grep without prior extraction.
* Built-in password manager with pattern auto-unlock for multipart release series.

#### [XBrowser](https://github.com/Robertkurniawan00/xbrowser)
A privacy-hardened desktop browser built with PyQt6 and QtWebEngine (Chromium).
* Built-in SOCKS5 Tor network routing for anonymous traffic and `.onion` domains.
* Content shields with local ad blocking, tracker protection, and WebRTC leak prevention.
* Workspace compartmentalization with isolated cookie jars and browsing sessions.
* Adaptive memory trimming and renderer process management for low-spec hardware.
